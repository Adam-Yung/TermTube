# src/strings.json

All UI wording, grouped by area (one top-level object per source module). Edit text here, not in the code. Look keys up with
`src.strings.text`; see `docs/code/src/strings.py.md` for placeholder rules and the keys that are built dynamically.
Wording rules: neutral and professional, sentence case, notices end with a period, "Delete" for files leaving the disk and "Remove" for
entries leaving a list.
