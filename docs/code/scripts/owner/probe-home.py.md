# scripts/owner/probe-home.py

Shows what the signed-in Home really holds, so a missing playlist or Mix row can be traced to its cause: yt-dlp not returning it, or TermTube dropping it. It reads the owner's browser cookies the way the app does, makes one throttled request to youtube.com, and prints counts of the raw rows by `ie_key`, `_type` and url prefix, how many `ytdlp.playlist_row` keeps and how many rows are playable videos, plus the first five playlist rows. No cookies or account data are printed. Owner-run only: an agent session must not run it. Decision context: `docs/decisions/playlist-page.md`.
